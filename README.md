# CHIP-8 Emulator in 4 Languages

My first GitHub project where I put what I've learned into real work.

CHIP-8 is a tiny virtual computer from the 1970s, originally designed to
make games easy to run on different machines. An emulator is a program that
pretends to be that computer.

## Why this project?
I didn't choose it, I rolled the dice.

## The plan
I'm writing the same emulator in four languages and giving my honest
reaction to each one.
